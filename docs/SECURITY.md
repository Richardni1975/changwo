# 畅吾欲言 — 安全设计文档

## 威胁模型

### 对手假设
1. **服务端被攻破**：攻击者获得 relay.js 服务器的 root 权限
2. **网络中间人**：攻击者可监听 Cloudflare ↔ 源站之间的流量
3. **恶意房间成员**：攻击者本身就是房间内的 50 人之一
4. **时序分析**：攻击者通过物理观察（如某人放下手机的时间）推断发送者

### 不在威胁模型内
- 客户端设备本身被攻破（如手机被植入木马）
- Cloudflare 基础设施被攻破
- 量子计算攻击

## 安全控制矩阵

| 威胁 | 控制措施 | 残余风险 |
|------|---------|---------|
| 服务端被攻破 → 身份泄露 | 零身份映射架构：服务端无 userId 字段，无关联表 | 无（架构层面杜绝） |
| 服务端被攻破 → 内容泄露 | XOR 分片仅在客户端合体，服务端只存加密碎片且 100ms 销毁 | 极低：攻击者需同时截获 4 枚碎片且在 100ms 窗口内 |
| 网络中间人 → 流量分析 | Cloudflare Tunnel 全程 TLS 加密；伪造混淆包混淆流量模式 | 低 |
| 时序分析 → 发送者推断 | 随机延迟漂移（50–350ms）+ 伪造混淆包 | 中：统计相关性在大量样本下仍可能存在 |
| 恶意成员 → 内容截图外泄 | 无法技术阻止（类似任何聊天工具） | 通过"熟人网络"的社会压力降低风险 |
| 重放攻击 | sessionToken 一次性绑定，重连需校验 | 低 |

## 代码审计清单（每次 PR 必检）

- [ ] ❌ 后端数据库无 `userId ↔ message` 关联表
- [ ] ❌ 客户端请求不携带 `OpenID` / `userId` / 设备指纹
- [ ] ❌ 服务端不记录任何可关联到真实身份的元数据
- [ ] ❌ 日志不输出 sessionToken 或任何可追溯标识
- [ ] ✅ 碎片桶 `assembled` 后 100ms 内销毁
- [ ] ✅ 房间容量 `MAX_ROOM_CAPACITY = 50`，非抢占式拒绝
- [ ] ✅ 原始语音文件本地转写后即时销毁
- [ ] ✅ 解密明文 7 天自动过期清理
- [ ] ✅ 所有 WSS 通信走 Cloudflare Tunnel，不暴露源站 IP
- [ ] ✅ `serverTs` 由服务端生成，客户端不可信

## 敏感数据生命周期

```
用户输入文本 ──▶ XOR分片（本地） ──▶ 原文明文销毁（本地）
    │
    ▼
4 枚加密碎片 ──▶ WSS 传输 ──▶ 服务端碎片桶（暂存 < 300ms）
    │                              │
    │                              ▼
    │                         assembled 广播
    │                              │
    │                              ▼
    │                         碎片桶销毁（100ms 内）
    │
    ▼
接收端收到碎片 ──▶ XOR 合体（本地） ──▶ 明文呈现
                                         │
                                         ▼
                                   IndexedDB 本地存储
                                         │
                                         ▼
                                   7 天后自动清除
```
