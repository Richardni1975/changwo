# 畅吾欲言 — 架构设计文档

## 1. 系统总览

畅吾欲言 是一款零知识（Zero-Knowledge）匿名沟通与集体决策工具，支持微信小程序和 PC Web 双端接入。系统核心设计理念为"服务端无感知"——所有身份映射在客户端物理隔离，服务端仅中转加密碎片，无法获知任何用户身份或消息明文。

## 2. 数据流：一次匿名消息的完整生命周期

```
发送端                          服务端                        接收端
  │                               │                              │
  │ 1. 用户输入文本                 │                              │
  │ 2. XOR 分片 → 4 枚乱码         │                              │
  │ 3. 本地销毁原文                 │                              │
  │                               │                              │
  │── shard[0] ──┐                │                              │
  │── shard[1] ──┤                │                              │
  │── shard[2] ──┼─ 随机延迟漂移 ──▶│                              │
  │── shard[3] ──┘                │                              │
  │                               │ 4. 碎片桶收集                  │
  │                               │ 5. 4片集齐 → assembled       │
  │                               │ 6. 100ms 内销毁碎片桶          │
  │                               │                              │
  │                               │── assembled(加密) ──────────▶│
  │                               │                              │ 7. 收到 assembled
  │                               │                              │ 8. XOR 逆运算合体
  │                               │                              │ 9. 呈现明文
  │                               │                              │ 10. 本地 IndexedDB 持久化
```

## 3. 密码学方案：客户端 XOR 分片

- **算法**：One-Time Pad (XOR) 分片
- **密钥**：4 枚客户端生成的随机字节串（每枚与明文等长）
- **分片**：`shard[i] = plaintext XOR randomKey[i]`
- **合体**：`plaintext = shard[0] XOR shard[1] XOR shard[2] XOR shard[3]`
- **安全保证**：缺少任意一枚碎片，攻击者无法恢复明文（信息论安全）

## 4. 防时序攻击

- 发送端引入 50–350ms 随机延迟漂移
- 服务端周期性地向房间广播伪造混淆包（与真实碎片包无法区分）
- 所有消息携带服务端时间戳，客户端不暴露本地时间

## 5. 关键设计决策记录

| 决策 | 理由 |
|------|------|
| Node.js 纯内存服务（无数据库） | 零身份映射强制约束，内存结构天然无持久化痕迹 |
| WebSocket 非 HTTP 轮询 | 50人实时通信需要双工通道，轮询延迟不可接受 |
| Cloudflare Tunnel 非直连 | 隐藏源站 IP，免费 SSL，抗 DDoS |
| 双端共享 Design Tokens JSON | 避免小程序和 Web 端视觉不一致 |
| 碎片在服务端不做 XOR 解谜 | 服务端零知识原则——即使服务器被攻破也无法获知明文 |
