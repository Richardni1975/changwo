# 知识库目录

隐蔽助教的知识库按「课程」分文件夹组织，**文件夹名 = 课程名**（也是老师面板下拉框里显示的课程名）。

## 目录结构

```
knowledge/
├── 创业课/          # 课程一（文件夹名即课程名）
│   ├── 01_*.md      # 课程书籍/讲义 Markdown 原文（中文）
│   ├── ...
│   └── index.json   # 由 kb-builder.js 生成的双字索引（勿手改）
├── 某课程二/        # 未来第二个知识库
└── ...
```

## 如何新增一门课程

1. 在 `knowledge/` 下新建一个文件夹，文件夹名就是课程名（如 `市场营销`）。
2. 把该课程的 Markdown 资料（中文）放进这个文件夹。
3. 运行构建脚本生成索引：

```bash
cd server && node kb-builder.js
```

脚本会扫描 `knowledge/` 下所有课程文件夹，为每门课生成 `index.json`（基于「字对 bigram」倒排索引，零成本本地检索，无需向量 embedding）。

## 注意

- 本目录下的课程内容与生成的 `index.json` **已加入 .gitignore**，不进入版本库（书籍内容涉及版权，索引可随时重建）。
- 服务端启动时会自动加载所有课程的 `index.json`；没有知识库时，助教的「建设性点评」角色自动停用，其余角色（暖场、鼓励）不受影响。
